# Resume Tailoring

Tailoring one canonical résumé to many job postings, in the author's own voice, without inventing experience.

## Language

**Canon**:
The author's master résumé, the single source every tailored résumé starts from.
_Avoid_: base resume, master, template

**Posting**:
The employer's text describing one open role.
_Avoid_: JD, job description, listing, job ad

**Application**:
One posting together with everything tailored for it.
_Avoid_: job, run

**Experience ledger**:
The author's standing record of experience confirmed or denied in past consultations, so the same question is never asked twice.
_Avoid_: profile, claims file, memory

**Batch**:
A set of applications processed together in one sitting.
_Avoid_: session, bulk run

**Batch summary**:
The single write-up for a batch, one short section per application.
_Avoid_: ATS report, report

**Consultation**:
The question phase where the author confirms experience and approves proposed changes before anything is written.
_Avoid_: interview, Q&A, review
